# UI 设计系统 v2 ——「温润玫瑰 · iOS 材质」（UI 设计师视角）

> 版本：v2（2026-10-29 全面重设计；2026-10-30 补暗色模式层） | 落地物：`uni.scss`（设计令牌，编译期）+ `theme.scss`（运行期颜色变量，暗色模式）+ `store/themeStore.uts`（主题状态）+ `components/lbc-*`（组件库）+ 本文档（规范）+ `test/unit/ui.test.js`（一致性回归网）
> v1 → v2 变更：珊瑚色系 → 玫瑰色系；灰墨文字 → 梅墨文字；圆角全面放大；新增动效标准块与按压反馈；新增暗色模式（全部 37 页令牌化）。

## 1. 设计原则

1. **记录优先**：任何页面中"记录动作"必须是一级可达；按钮主次分明，主按钮唯一。
2. **玫瑰不糖果**：玫瑰主色是页面上唯一的高声量颜色，其余全部低声（腮红白画布 + 梅墨文字）；渐变只给每页唯一的英雄卡/主 CTA，不做满屏糖果渐变。情感表达放在仪式感场景（英雄卡、出生卡、里程碑），数据界面保持信息设计的克制。
3. **Apple 材质分层**：腮红白画布 → 纯白浮起卡片（极浅梅子投影）→ 卡内彩色浅底芯片（iOS 设置页式）。层级靠浅底色与投影，不靠描边。
4. **大圆角连续曲面**：卡片 36rpx、英雄卡 40rpx、芯片 24rpx、胶囊按钮全圆；观感圆润但不失结构。
5. **安全感**：医疗红线提示固定样式（红·图标·动作按钮三要素，`#E5484D` 专用不挪用），与普通提示严格区分；免责声明组件统一样式。
6. **深夜可用**：产褥期核心场景，大点击区（最小 88rpx 高）+ 低亮度友好；动效一律 160–520ms 短促，不做长驻动画（计时脉冲除外）。

### 2.2 字体/间距/圆角/投影

- 字号：`32/28/24/22/20rpx`（标题/正文/辅助/标签/说明）；大数值输入 88rpx、计时器 96rpx、英雄周数 56rpx。**app 端文字必须置于 text 组件内，样式不可继承——组件内全部显式声明。**
- 间距体系：`8/16/24/32/48rpx`（xs…xxl）。
- 圆角：英雄卡 40rpx、卡片 36rpx、芯片/内嵌块 24rpx、小标签内芯 20rpx、胶囊按钮 48rpx（高 96 即全圆）、正圆（计时大按钮 160rpx）保持。
- 投影：静态卡 `0 6rpx 24rpx rgba(50,36,48,0.04)`（可省）；英雄/主 CTA `0 12rpx 32rpx rgba(228,83,127,0.28)`；悬浮层/弹窗 `0 16rpx 48rpx rgba(50,36,48,0.18)`。禁用更重投影。

## 3. 动效标准块（每页 style 末尾内嵌，`test/unit/ui.test.js` 强制）

```css
@keyframes lb-rise { from { opacity: 0; transform: translateY(28rpx); } to { opacity: 1; transform: translateY(0); } }
@keyframes lb-pop { from { opacity: 0; transform: scale(0.92); } to { opacity: 1; transform: scale(1); } }
@keyframes lb-fade { from { opacity: 0; } to { opacity: 1; } }
@keyframes lb-pulse { 0% { opacity: 1; } 50% { opacity: 0.45; } 100% { opacity: 1; } }
.lb-rise   { animation: lb-rise 520ms cubic-bezier(0.22, 1, 0.36, 1) both; }
.lb-rise-1 { animation: lb-rise 520ms cubic-bezier(0.22, 1, 0.36, 1) 70ms both; }
.lb-rise-2 { animation: lb-rise 520ms cubic-bezier(0.22, 1, 0.36, 1) 140ms both; }
.lb-rise-3 { animation: lb-rise 520ms cubic-bezier(0.22, 1, 0.36, 1) 210ms both; }
.lb-pop  { animation: lb-pop 240ms cubic-bezier(0.22, 1, 0.36, 1) both; }
.lb-fade { animation: lb-fade 200ms ease-out both; }
.lb-press { opacity: 0.72; transform: scale(0.98); }
```

用法（动效只回答动作，不装饰）：
- **进场**：页面主要区块依次挂 `lb-rise / lb-rise-1 / lb-rise-2…`，每页一次性编排，不做滚动触发。
- **按压**：所有可点卡片/行/选项加 `hover-class="lb-press" hover-stay-time="120"`，基础 class 加 `transition: all 160ms ease-out;`。纯静态卡不加（learn 页为反例豁免）。`<text>` 不支持 hover-class 时外包一层 view 承载。
- **弹层**：mask 挂 `lb-fade`、内容容器挂 `lb-pop`。
- **计时进行中**：状态点/呼吸提示挂 `animation: lb-pulse 1.6s ease-in-out infinite;`。
- 约束：app 端 transition/animation 只写整体简写（不支持拍平展开）；仅 class 选择器。

### 5.2 记录 Tab

顶部"快捷宫格（与首页一致，芯片化）+ 全部记录项分组列表（孕期/备孕/产后）"；计时器进行中时顶部出现 `lbc-timer-bar`。

### 5.3 产检详情

时间线左侧锚点（已完成✓薄荷/进行中玫瑰/未到藕灰）+ 右侧项目清单卡片；底部主按钮"录入本次产检"；报告缩略图九宫格，点开大图 + AI 解读入口（V1.1 灰置）。

### 5.4 红线提示交互

任何红线触发（血压≥160/110、5-1-1 宫缩、血便、破水）：全屏半屏弹层 → 危险色头部图标 + 一句话现象 + 「建议动作」按钮（呼叫家人/去最近的医院）+ "我知道了"。**每 24h 同类红线只弹一次，其余时间收敛为页面内横幅。**

## 6. 交互细节约定

- 表单类记录页统一：顶部大数值输入区（88rpx 数字 + 玫瑰底线）→ 细节字段折叠 → 底部固定「保存」（胶囊主按钮）；保存成功 toast + 返回上一页并局部刷新。
- 计时器类：进入即大按钮（玫瑰渐变圆 / 停止态纯红 #E5484D）；计时中可锁屏/切后台；恢复后时间校准（用服务端/设备绝对时间差）。
- 所有列表空态给"第一步"引导；所有破坏性操作（删除记录/退出家庭）二次确认（自绘弹窗：mask lb-fade + 内容 lb-pop）。
- 数字键盘输入完成后自动收起；保存按钮在表单脏时才可点。

## 7. 暗色模式（theme.scss + themeStore，2026-10-30）

### 7.1 机制

- **双层令牌**：`uni.scss` 是编译期 SCSS 令牌（几何/字号/间距 + 色彩事实源）；`theme.scss` 定义 `.t-light` / `.t-dark` 两个 class 上的 `--lb-*` CSS 变量（仅颜色，运行期可切换）。`.t-light` 取值与 uni.scss 色彩令牌**同源**（`test/unit/ui.test.js` 强制对齐）。
- **接入方式**：页面根节点 `<view class="page" :class="themeClass()">`（uni-app x App 端无 `:root`，官方推荐根节点定义变量 + 子元素 `var()` 引用）；页面 style 内所有颜色写 `var(--lb-*)`，不写十六进制字面量。
- **状态**：`store/themeStore.uts` 持久化 `light|dark`（`lb_theme`），`themeClass()` 响应式返回主题 class；设置页开关直连 `setThemeMode`。「跟随系统」待 manifest darkmode + theme.json 验证后开放。
- **保留字面量的颜色**：英雄卡/主 CTA 渐变（`#F0709D→#DC3D75`，两主题通用）、图表数据色（`#F5A3C3`/`#F2B7CB` 柱与点，暗底上可读）、按钮上的白色文字（主色/渐变/危险底在两主题下均为深色背景）。
- **已知限制**：原生导航栏与 tabBar 保持浅色配置（uni-app x 动态改栏色 API 待 HBuilderX 实测）；`page` 窗口底色仍为腮红白（被页面根节点全幅背景覆盖，仅下拉回弹处可见）。

### 7.2 暗色取值（玫瑰暗夜）

页面底 `#1A1418`（梅黑）→ 卡片 `#251D24` → 次级浅底 `#2E2430`；文字 `#F5EEF3 / #B7A9B6 / #7C6F7B`；主色提亮为 `#F0749F`（按压/浅底上文字用 `#F5A3C3`）、鸢尾紫 `#A79AF0`、薄荷 `#52C29B`、琥珀 `#F0AC4F`、红线 `#FF7B80`；遮罩转纯黑半透明 `rgba(0,0,0,0.6)`；芯片五色换为对应深色浅底。原则：暗色不是反色，是「同一种玫瑰在夜里的样子」——色相不变、明度重排。
