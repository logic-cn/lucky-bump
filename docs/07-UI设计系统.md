# UI 设计系统（UI 设计师视角）

> 版本：v0.1 | 落地物：`uni.scss`（设计令牌）+ `components/lbc-*`（组件库）+ 本文档（规范）

## 1. 设计原则（对齐 02-§1.4）

1. **记录优先**：任何页面中"记录动作"必须是一级可达；按钮主次分明，主按钮唯一。
2. **温暖但不幼态**：主色用暖珊瑚系而非糖果色；情感插画/吉祥物只出现在仪式感场景（好孕报、出生卡、里程碑），数据界面保持信息设计的克制。
3. **安全感**：医疗红线提示固定样式（红·图标·动作按钮三要素），与普通提示严格区分；免责声明组件统一样式（灰底小字）。
4. **深夜可用**：产褥期核心场景，暗色适配 + 大点击区（最小 88rpx 高）+ 低亮度友好。

## 2. 设计令牌（uni.scss）

### 2.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `$lb-primary` | #FF7A6B（暖珊瑚） | 主按钮/选中态/阶段强调 |
| `$lb-primary-deep` | #E85D4E | 按压态 |
| `$lb-primary-soft` | #FFEFEA | 主色浅底（标签、选中底） |
| `$lb-secondary` | #6BA3FF（雾蓝） | 爸爸端/家庭共享主题色 |
| `$lb-success` | #4CAF7D | 达标/正常 |
| `$lb-warning` | #F5A623 | 临界提醒 |
| `$lb-danger` | #E5484D | **红线提示专用**（不挪作它用） |
| `$lb-bg` | #F7F6F4（暖灰白） | 页面底 |
| `$lb-card` | #FFFFFF | 卡片 |
| `$lb-text-1/2/3` | #1F2329 / #6B7280 / #A3AAB5 | 标题/正文/辅助 |
| `$lb-line` | #EDEBE8 | 分隔线 |

暗色模式：页面底 #17181A、卡片 #222427、文字反转、主色不变；令牌通过 `--lb-*` CSS 变量 + `@media (prefers-color-scheme)` 在 web 生效，app 端用 store 主题值切换 class。

### 2.2 字体/间距/圆角

- 字号：`32/28/24/22/20rpx`（标题/正文/辅助/标签/说明）；数字大卡 64rpx。**app 端文字必须置于 text 组件内，样式不可继承——组件内全部显式声明。**
- 间距体系：`8/16/24/32/48rpx`（xs…xxl）。
- 圆角：卡片 24rpx、按钮 44rpx（全圆角主按钮）、标签 12rpx。
- 阴影：仅一层 `0 4rpx 16rpx rgba(31,35,41,0.06)`，禁用重投影。

| `lbc-grid-record` | 快捷记录宫格 | 图标+名称，长按排序，阶段动态数据驱动 |

## 4. 关键页面布局规范

### 4.1 今天（首页）

```
┌ NavBar: 幸孕记 · [阶段徽标]  ┌ 右: 家庭头像组
├ 阶段大卡: 孕 24 周 + 3 · 距预产期 108 天 · 宝宝大小可视化（水果图 + 600g）
├ 今日待办卡: [糖耐检查 09:00 · 已备好清单 ▸]  （无待办 → 鼓励文案）
├ 快捷记录宫格 2×4: 体重 血压 胎动 宫缩 症状 日记 更多…
├ 趋势摘要卡: 本周体重 +0.4kg（区间内 ✓） 血压均值 118/76
└ 家庭动态卡: 爸爸今天记了 2 次夜奶 ❤
```

### 4.2 记录 Tab

顶部"快捷宫格（与首页一致）+ 全部记录项分组列表（孕期/备孕/产后）"；计时器进行中时顶部出现 `lbc-timer-bar`。

### 4.3 产检详情

时间线左侧锚点（已完成✓/进行中/未到）+ 右侧项目清单卡片；底部主按钮"录入本次产检"；报告缩略图九宫格，点开大图 + AI 解读入口（V1.1 灰置）。

### 4.4 红线提示交互

任何红线触发（血压≥160/110、5-1-1 宫缩、血便、破水）：全屏半屏弹层 → 危险色头部图标 + 一句话现象 + 「建议动作」按钮（呼叫家人/去最近的医院）+ "我知道了"。**每 24h 同类红线只弹一次，其余时间收敛为页面内横幅。**

## 5. 交互细节约定

- 表单类记录页统一：顶部大数值输入区 → 细节字段折叠 → 底部固定「保存」；保存成功 toast + 返回上一页并局部刷新。
- 计时器类：进入即大按钮；计时中可锁屏/切后台；恢复后时间校准（用服务端/设备绝对时间差）。
- 所有列表空态给"第一步"引导；所有破坏性操作（删除记录/退出家庭）二次确认。
- 数字键盘输入完成后自动收起；保存按钮在表单脏时才可点。
