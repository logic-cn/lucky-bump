# 外部依赖与后续接入清单

> 2026-11-02 整理。列出的能力**无法仅靠本仓代码完成**，需要控制台配置、外部服务、硬件或平台能力；代码侧已做的兜底一并注明。

## 1. 服务端远程推送

| 项 | 说明 |
|---|---|
| 现状 | App 端 `utils/notify.uts` 已用 `uni.createPushMessage` 注册未来 14 天本地通知（锁屏可达），Web 端 `utils/webNotify.uts` 已接浏览器通知；站内待办正常。 |
| 缺口 | 跨设备/服务端主动推送（换机、未打开 App 时的运营触达）。 |
| 依赖 | DCloud uni-push 控制台开通 + Android/iOS 推送证书 + 云函数侧 `uniCloud.getPushManager({ appId })` 调用。 |
| 接入步骤 | ① HBuilderX 云空间开通 uni-push → ② 上传各厂商证书 → ③ 客户端 `uni.getPushClientId` 注册并上报 cid → ④ 云函数定时/事件触发送达。 |
| 风险 | 推送内容必须遵守「免打扰时段 / 哀伤模式零推送」红线，接入时需在发送侧统一过 `utils/quiet.uts` 同口径门禁。 |

## 2. AI 能力

| 能力 | 现状 | 依赖 |
|---|---|---|
| 产检报告解读 | 报告照片仅存储与展示；红线提示为规则引擎 | 外部多模态 AI 服务 + 医疗合规评审；输出须限制为「正常 / 常见偏离科普 / 建议咨询医生」三类 |
| 排卵试纸图像判读 | 试纸照片可上传保存，判读依赖人工 | 图像识别服务（LH 深浅分级） |
| AI 儿保单识别 | 儿保页已支持手工录入全部字段 | OCR + 结构化抽取服务 |
| AI 问答助手 | 未做（V2.0 规划） | 大模型服务 + 医疗内容审核流程 |

代码侧已把「AI 入口」与「规则解读」分离：红线（`lucky-record` 规则引擎）、报告（`lucky-data.report`）均不依赖 AI，可在无外部服务时完整工作。

## 3. 蓝牙硬件

| 硬件 | 用途 | 依赖 |
|---|---|---|
| 蓝牙体温计 | BBT 自动写入 | 厂商 SDK + uni-app x 蓝牙插件 |
| 蓝牙体脂秤 | 体重自动写入 | 厂商 SDK + 平台权限 |

现有手工录入路径完整，硬件接入只影响录入便利性。

## 4. 平台能力

- **暗色导航栏 / tabBar**：uni-app x 动态改栏色 API 待 HBuilderX 版本验证（manifest darkmode + theme.json），页面内暗色已完成。
- **真机回归**：无设备连接时无法自动执行，使用 `scripts/device-regression.sh`。

## 5. 明确不做（产品红线 / 战略）

- 会员付费墙、广告、商城、社区、资讯流：记录能力永久免费，不做流量变现。
- 药品剂量推荐：仅记录，不提供剂量建议。
