# 幸孕记（Lucky Bump）数据模型与页面结构

> 文档版本：v0.1
> 文档目的：定义核心数据实体、关系与关键字段，以及主要页面清单，供研发与设计对齐。
> 设计基调：以「旅程（Journey）」为数据主线，所有记录实体归属于旅程或宝宝，天然支持多旅程（二胎）与多宝宝（多胎）。

---

## 2. 核心实体与关键字段

> 仅列关键字段；通用字段（id、created_at、updated_at、deleted_at、source[手动/蓝牙/AI识别]、created_by[家庭成员]）不再赘述。

### 2.1 用户与家庭

| 实体 | 关键字段 | 说明 |
|---|---|---|
| User | 手机号/昵称/头像/身高/孕前体重/出生年份 | 孕前 BMI 由身高体重推导 |
| Journey | `stage_code`(PRECONCEPTION/T1/T2/T3/POSTPARTUM/RECOVERY/PARENTING/ARCHIVED/MOURNING) / `lmp_date` / `edd`(预产期) / `edd_source`(LMP/ULTRASOUND/IVF/USER) / `ultrasound_corrections[]` / `fetus_count`(1/2/3) / `ivf_transfer_date` / `ivf_transfer_type`(D3/D5) / `high_risk_flags[]` | 全产品时间源 |
| Baby | journey_id / 小名 / 性别(未出生为 UNKNOWN) / 出生日期 / 出生体重/身长 / `is_archived` | 多胎 = 多条记录 |
| Family / FamilyMember | 角色(ADMIN/RECORDER/VIEWER) / 数据组授权矩阵(JSON) / 加入时间 | 见 03-M7 |

### 2.2 备孕

| 实体 | 关键字段 |
|---|---|
| Cycle | 周期开始日/结束日/周期长度/经期天数 |
| CycleEvent | `type`(MENSAGE/OVULATION_TEST/BBT/INTERCOURSE/PREGNANCY_TEST) / 结果枚举 / 数值 / 照片 / `is_sensitive`=true | INTERCOURSE、PREGNANCY_TEST 强制敏感组 |

### 2.3 孕期记录

| 实体 | 关键字段 |
|---|---|
| DailyLog / MetricValue | `metric_code`(WEIGHT/BP/BLOOD_GLUCO/HHCG/PROGESTERONE/FETAL_MOVEMENT/AMNIOTIC…) / 数值(结构化 JSON，BP={sbp,dbp,hr}) / 孕周快照(week, day) | 孕周快照保证孕周修正后历史可解释 |
| Symptom | 症状码 / 严重度(1-3) / 备注 / 红线触发标记 |
| TrackerSession | `type`(CONTRACTION/NURSING/PUMPING) / 开始/结束 / 侧别 / 计量 | 宫缩记录供 5-1-1 判定 |
| PrenatalVisit | 日期/医院/医生/孕周/费用/结论备注/下次产检日期 |
| ExamItem | 项目码(NT/唐筛/OGTT/大排畸/GBS…) / 结果 / 是否异常 / 数值 | 与报告识别结果关联 |
| ScheduleItem | `kind`(产检/疫苗/儿保/复诊/自定义) / 计划时间 / 实际时间 / 状态 / 准备清单(JSON) | 提醒引擎的排程载体 |
| DiaryEntry | 文本/图片/音频 / `mood` / is_sensitive |
| Screening | `type`(EPDS) / 答题 JSON / 总分 / 第 10 题分值 / 建议动作 | 永远敏感、不可授权 |

### 2.4 产后与育儿

| 实体 | 关键字段 |
|---|---|
| Delivery | 分娩日期时间/方式/侧切撕裂/医院/Apgar | 触发 Baby 创建与产褥期时钟 |
| PostpartumLog | 恶露颜色/量/异常标记；凯格尔完成组数；伤口状态 |
| Feeding | `mode`(亲喂/瓶喂母乳/奶粉/混合) / 侧别 / ml / 时长秒 / 补录标记 |
| DiaperChange | 尿/便 / 便性状 / 颜色 / 异常标记(血丝/陶土色/水样) |
| SleepSession | 入睡/醒来 / 类型(夜间/小睡) / 夜醒计数 |
| GrowthSample | 身高cm/体重kg/头围cm / 测量月龄(实际+矫正) / 百分位缓存(3 指标) / 来源(手动/儿保/AI识别) |
| Vaccination | 疫苗码 / 剂次 / 计划日期 / 接种日期 / 批号 / 接种点 / 反应备注 / `is_free`(免疫规划/自费) |
| Milestone | 维度(大运动/精细/语言/社交) / 项目码 / 达成日期 / 媒体 / 参考月龄区间 |
| FoodLog | 食物 / 首次标记 / 观察窗(id, day1-3) / 反应枚举 / 过敏确认标记 |
| MedicationLog | 药名/剂量/时间/原因/说明书照片 |
| MediaAsset | 文件 / 月龄快照 / 相册归属 / 敏感标记 |

### 2.5 提醒与运营

| 实体 | 关键字段 |
|---|---|
| ReminderRule | 类型(绝对/相对孕周/相对月龄/周期) / 锚点 / 提前量 / 紧急级别 / 免打扰豁免 / 状态 |
| NotificationLog | 送达/点击/处理结果 | 驱动"提醒疲劳"调优 |

### 2.6 数据分组与权限（实现要点）

- 所有记录实体携带 `sensitivity_group` 字段（NONE/SENSITIVE），家庭共享按「数据组 × 角色」授权矩阵过滤；
- 同房记录、EPDS 量表服务端硬编码为"仅本人"，授权矩阵不可覆盖；
- 云端存储按 Journey 分片，跨旅程数据物理隔离。

## 4. 关键状态与开关（Feature Flags）

| Flag | 用途 |
|---|---|
| `ai_report_scan` | AI 报告识别灰度 |
| `family_share_v1` | 家庭共享（默认开，可按渠道关） |
| `mourning_mode` | 哀伤模式（永不可灰度关闭，保证可用性） |
| `tracker_background` | 计时器后台运行（受各平台权限限制） |
