## 1. 项目背景与目标

### 1.1 一句话描述

做一个**覆盖「备孕 → 孕早/中/晚期 → 分娩 → 产褥期 → 产后恢复 → 0-3 岁育儿」全生命周期**的孕期管理 APP，以**结构化记录**为核心，帮助女性和家庭把人生中最重要的 3-4 年，变成一份连续、完整、可回顾的健康数据资产。

### 1.2 为什么要做（问题陈述）

当前母婴工具市场存在一个结构性割裂：

- **经期/备孕类**产品（同类产品、Flo）强在周期预测，一旦怀孕成功，用户被迫迁移到另一个孕期产品；
- **孕期类**产品（孕期类产品、妈妈网）重内容与社区，记录功能浅（多数只是体重打卡），产检报告只能拍照存相册；
- **育儿类**产品（育儿类产品）强在相册与家庭共享，但与前序孕期数据完全断开。

**结果是：一位女性在 3-4 年的生命周期里，要在 3-4 个 APP 之间反复迁移，她的健康数据在每次迁移中丢失、割裂。** 月经期、排卵、验孕、产检、分娩、喂养、成长曲线——这些本该是**一条连续的生命数据链**，现在散落在若干个 APP、手机相册、微信收藏和纸质手册里。

### 1.3 产品目标

1. **用户价值**：一个 APP 走完全流程，数据不断档；记录足够快（核心动作 ≤ 2 步），让"坚持记录"成为可能。
2. **产品价值**：用「阶段引擎 + 数据连续性」对抗母婴工具最大的魔咒——**阶段毕业即流失**（生完就卸载）。
3. **商业价值**：生命周期长（备孕到育儿约 3-4 年），用户生命周期价值 空间大；记录数据是最高迁移成本的护城河，也是会员、内容、电商等变现模式的信任基础。

## 2. 市场与机会分析

> 以下数据为立项阶段的量级估算，正式立项前需引用最新权威数据源（国家统计局、易观、艾瑞、QuestMobile）复核。

### 2.1 市场基本盘

| 维度 | 量级估算 | 对产品的含义 |
|---|---|---|
| 年出生人口 | 约 900-1000 万/年（2024 年约 954 万，止跌回升） | 每年有近千万级新用户进入"孕产期" |
| 活跃用户池 | 任一时点，处于备孕+孕产+0-3 岁阶段的女性约 5000 万+ | 市场盘子足够大，且逐年滚动补给 |
| 母婴消费市场 | 3-4 万亿/年（产品+服务），健康类服务增速领先 | 记录工具是高频入口，后向变现空间大 |
| 工具渗透率 | 头部孕期 APP 合计月活约 3000 万+，但留存分层严重 | 用户教育已完成，拼的是产品力而非市场教育 |

### 2.2 需求侧的三个时代变化

1. **科学育儿一代**：90/95 后父母默认"数据化养娃"，愿意记录、看得懂曲线、对 WHO 标准有认知。记录行为从"少数人的坚持"变成"多数人的期待"。
2. **爸爸参与度提升**：新一线城市家庭中爸爸深度参与（陪产检、夜奶、换尿布）比例显著上升，但**几乎没有一款产品为"参与者"设计**，现有产品全部默认用户是妈妈本人。
3. **AI 重构记录工具**：拍照识别报告、口语化问诊、智能解读指标成为可能。上一代孕期 APP 的内容堆砌模式（海量文章 + 信息流）正在被"基于你的记录数据给出场景化答案"替代。

### 2.3 供给侧的结构性机会

- **没有人做"数据连续性"**：全行业按阶段割粉，一款产品吃一个阶段，用户迁移 = 数据重来。全流程一体 + 数据不断档是未被占领的心智。
- **记录深度普遍不足**：现有产品记录多为"打卡式"（今天称了体重），缺少面向就医决策的结构化记录（血压趋势、胎动模式、喂养摄入量、成长百分位）。
- **隐私痛点被低估**：孕产数据是极其敏感的个人信息（流产史、同房记录、产后抑郁筛查），用户对大厂 APP 的数据滥用有普遍焦虑，"隐私优先"是可以做成口碑的差异化。

## 3. 市场参照

> 结论先行：**单品类的记录深度我们做不过深耕者，但"全流程 + 数据连续 + 家庭协作 + 隐私"的组合无人占据，这是我们的主战场。**

### 3.1 国内主要同类产品

| 同类产品 | 定位 | 优势 | 劣势（我们的机会） |
|---|---|---|---|
| 同类产品 | 经期管理 → 孕期延伸 | 周期预测算法成熟、用户基数大、品牌认知强 | 广告重、社区信息质量参差；孕期记录浅；产后育儿基本缺位 |
| 孕期类产品 | 孕育内容+社区+电商 | 内容积累深、专家背书、商业变现成熟 | 产品重、路径长；记录工具弱；体验被商业化侵蚀 |
| 孕期社区产品 | 孕期社区+工具 | 同城妈妈社区粘性强 | 工具记录弱，偏社区电商 |
| 育儿类产品 | 育儿相册+记录+家庭共享 | 家庭共享和隐私口碑极佳、育儿期留存好 | 从育儿切入，无孕期/备孕数据；相册属性重、健康管理弱 |
| 孕期知识产品 | 权威内容+课程 | 内容权威、医疗信任度高 | 工具属性弱，更像知识付费产品 |

### 3.2 海外对标（产品设计参考）

| 同类产品 | 值得借鉴的点 |
|---|---|
| 海外周期类产品 | 周期预测与孕期周报的体验打磨；数据洞察报告做成周更仪式感 |
| 海外孕期类产品 | 按孕周推送"本周该做什么"的待办体系；产检准备清单 |
| 海外育儿记录产品 | **育儿记录的极简设计标杆**：一键记录喂养/睡眠/尿布，AI 睡眠建议 |
| 海外备孕记录产品 | 备孕 TTC（trying to conceive）社区的记录深度：排卵试纸拍照识别、BBT 双相曲线 |

### 3.3 竞争策略

- **不与同类产品拼周期预测、不与育儿类产品拼相册、不与孕期类产品拼内容量**。
- 抢占一个复合心智：**「从备孕到育儿，一条不断档的生命记录」**。
- 用"记录深度 + 快"建立工具口碑，用"家庭共享 + 隐私"建立情感与信任口碑。

## 4. 目标用户与用户画像

### 4.1 用户构成

- **核心用户（P0）**：备孕女性、孕妇、0-1 岁新手妈妈本人。
- **重要用户（P1）**：准爸爸/爸爸（参与者角色，通过家庭共享进入）。
- **延伸用户（P2）**：双方长辈（只读围观）、二胎妈妈（回流用户）。

### 4.2 用户画像

**画像 A：小雅，28 岁，备孕中（占比预期 ~20%）**

- 一线城市互联网从业者，月经周期不规律（32-38 天），已备孕 5 个月。
- 行为：同时用同类产品（记录经期）+ Flo（看英文科普）+ 小红书搜攻略；排卵试纸拍照发群问"这算强阳吗"。
- 痛点：① 排卵预测不准，试纸结果没人帮看；② 备孕知识碎片化且互相矛盾；③ 每个月"等待判决"的焦虑无人可诉。
- 她需要：可靠的易孕窗口预测、试纸/体温的结构化记录与趋势解读、克制的知识推送（而不是贩卖焦虑）。

**画像 B：芳芳，31 岁，孕 24 周，职场妈妈（占比预期 ~50%，主力用户）**

- 管理咨询顾问，产检主要利用午休和周末；丈夫出差多，常独自产检。
- 行为：产检报告拍照存相册、下次产检时间记在手机日历、体重随手记在备忘录；加入 3 个孕妈群，报告截图发群里问。
- 痛点：① 产检流程懵——每次该查什么、要不要空腹、要带什么，全靠问人；② 报告看不懂，指标异常无从判断；③ 记录分散在相册/日历/备忘录，无法形成趋势；④ 体重增长焦虑，不知道自己的增重是否正常。
- 她需要：自动生成的产检日程与准备提醒、报告拍照归档并结构化、关键指标趋势曲线、"什么情况该去医院"的清晰红线。

**画像 C：丽丽，29 岁，产后 3 个月，新手妈妈（占比预期 ~30%）**

- 产后进入喂养-睡眠-恢复的三重混乱期，日均睡眠 5 小时。
- 行为：靠记忆记奶量（经常忘）、宝宝大便颜色拍照问群、产后情绪低落但"觉得自己矫情"。
- 痛点：① 喂养/睡眠/尿布记录在疲惫状态下必须极简，最好单手 3 秒完成；② 宝宝生长是否达标没有权威参照；③ 产后情绪问题被忽视，现有的 APP 只关心宝宝不关心她。
- 她需要：3 秒级记录（计时器、快捷按钮）、WHO 百分位成长曲线、疫苗接种提醒、**面向妈妈自己的产后情绪关注**。

**画像 D：阿哲，32 岁，准爸爸（P1 用户）**

- 想参与但无从下手：产检听不懂、夜奶帮不上、"老婆孕吐我只能干着急"。
- 痛点：没有一款产品给他"参与者视角"——他不需要社区和种草，需要的是：今天宝宝多大啦、我该做什么（陪产检/买什么/做什么饭）、她的状态如何。
- 他需要：家庭共享下被精心设计的"爸爸端视图"，把"围观者"变成"参与者"。

## 5. 用户旅程地图

> 按"阶段 × 关键时刻"梳理，标注情绪低谷（= 机会点）。完整的功能落点见 03 号文档。

| 阶段 | 关键时刻（触点） | 用户情绪 | 痛点/机会点 |
|---|---|---|---|
| 备孕 | 每次大姨妈降临 | 失落、自我怀疑 | 现有产品无情绪承接；机会：温和的记录反馈与下周期规划，不贩卖焦虑 |
| 备孕 | 排卵试纸"疑似强阳" | 紧张、不确定 | 机会：试纸拍照识别 + 官方判读参考 + 同房窗口提醒（备孕核心闭环） |
| 备孕→怀孕 | **验孕棒两道杠** | 人生级峰值情绪 | **最大转化时刻**：机会是"好孕确认"仪式（自动生成好孕报、数据无缝切换到孕周模式、一键告知爸爸）。现有产品此处体验普遍断裂 |
| 孕早期 | 6-8 周 B 超确认胎心 | 极度紧张→狂喜 | 机会：建档引导（12 周前）、hCG/孕酮翻倍记录工具 |
| 孕早期 | 孕吐严重时 | 低谷 | 机会：症状记录 + 缓解科普 + "严重到什么程度该就医"红线 |
| 全孕期 | 每次产检前后 | 规律性焦虑 | 机会：产检日程自动生成、检查前准备提醒（空腹/憋尿/带什么）、报告拍照结构化——**这是使用频次与价值感最高的功能簇** |
| 孕晚期 | 半夜宫缩 | 慌张 | 机会：宫缩计时器 + 5-1-1 规则自动提示就医时机 + 待产包核对 |
| 分娩 | 出生那一刻 | 人生峰值 | 机会：分娩登记的仪式感设计（出生卡、分享图），这是产品情感资产 |
| 产褥期 | 深夜第 3 次夜奶 | 身心俱疲 | 机会：单手 3 秒记录（计时器模式）、按需推送（默认极简，绝不深夜打扰） |
| 产后 | 产后 2-6 周 | 情绪低谷高发 | 机会：EPDS 产后情绪自评 + 温和的求助引导——现有产品几乎无人做，这是差异化口碑点 |
| 育儿 | 每次儿保 | 常态化 | 机会：成长曲线（WHO 百分位）+ 疫苗/儿保日程自动生成 |
| 育儿 | 宝宝第一次翻身/走路 | 峰值 | 机会：里程碑记录 + 时光轴回顾，喂养情感留存 |
| 全程 | 换 APP/换手机/生二胎 | 不安 | 机会：数据导出、多宝宝档案、再备孕模式（老用户回流闭环） |

**旅程结论**：产品必须接住 3 个"人生级时刻"（验孕成功、分娩、宝宝里程碑），服务好 3 类"高频焦虑"（产检、症状、生长是否达标），并把记录成本压到疲惫状态下也能完成。

## 6. 核心洞察（战略假设）

1. **阶段流转即留存**：母婴工具的流失本质是"阶段毕业"。全流程设计的首要目标不是功能全，而是让用户在阶段切换时（怀孕确认/分娩/产后 6 周）数据无缝过渡、认知平滑切换，把 3-4 年生命周期留在同一个数据资产里。
2. **记录是核心，内容是辅助，社区是后置**：记录产生数据资产（迁移成本=留存护城河），内容按"本周该做什么"场景化裁剪（对抗信息过载），社区是 V2 之后的事——早期做社区是资源黑洞。
3. **为参与者设计**：家庭共享不是"多一个账号"，而是给爸爸重新设计的信息架构（该我做什么）。它同时解决传播（拉新）和情感绑定（留存）。
4. **AI 是这一代产品的及格线**：报告识别与解读、口语化问答、基于个人数据的建议（带免责边界），让"记录"产生"洞察"，完成从记事本到健康助手的跃迁。
5. **信任是健康产品的命门**：不诊断、红线清晰（数据异常只提示就医不吓唬人）、隐私默认最小化。短期牺牲一点"提高粘性"的推送策略，换取长期口碑。

## 7. 需求汇总与 KANO 分级

> 功能的定义与验收标准见 03 号文档；此处解决优先级问题。

### 7.1 基本型需求（不做就是不及格）

| # | 需求 | 对应旅程痛点 |
|---|---|---|
| B1 | 孕周/预产期计算（支持末次月经/B超校正/试管移植日） | 全孕期基础 |
| B2 | 经期与排卵记录、易孕窗口预测 | 备孕核心闭环 |
| B3 | 孕期基础记录：体重、血压、症状、情绪 | 日常健康监测 |
| B4 | 产检日程自动生成 + 检查前提醒 + 产检记录/报告归档 | 产检焦虑（最高频价值） |
| B5 | 胎动计数、宫缩计时（临产工具） | 孕中晚期刚需 |
| B6 | 分娩登记 + 出生后基础记录（喂养/尿布/睡眠） | 产褥期刚需 |
| B7 | 提醒引擎（产检/疫苗/复诊/打卡） | 全程 |
| B8 | 数据曲线与时间线、数据导出 | 记录的意义感 |
| B9 | 隐私保护（应用锁、敏感记录单独隐藏、本地优先） | 信任底线 |

| # | 需求 | 说明 |
|---|---|---|
| E1 | 产检报告拍照识别（OCR→结构化→关键指标高亮与科普） | AI 差异化的第一个落点 |
| E2 | WHO/CDC 成长曲线（百分位）与儿保记录 | 育儿期核心 |
| E3 | 国家免疫规划疫苗程序表 + 自费疫苗管理 + 漏种提醒 | 育儿高频刚需 |
| E4 | 里程碑记录（大运动/精细/语言/社交）+ 时光轴 | 情感留存 |
| E5 | 家庭共享与"爸爸端"视图 | 传播与参与感 |
| E6 | 孕期增重区间（按孕前 BMI）与恢复曲线 | 焦虑缓解 |
| E7 | 辅食记录（新食物 3 天观察法）与忌口提示 | 6 月龄后刚需 |
| E8 | 产后情绪自评（EPDS）与产后 42 天检查管理 | 差异化关怀 |
| E9 | 里程碑式报告：孕周周报、分娩报告、年度孕育报告（可分享） | 自传播 |
| E10 | 多宝宝/双胞胎档案、二胎再备孕模式 | 生命周期闭环 |

| X6 | 月子/月嫂/导乐等服务对接 | 重资产，不做自营 |

## 8. 范围界定（本版本明确不做的事）

> 资深产品经理的第一要务是定义"不做什么"。

1. **不做医疗诊断**：所有数据解读均为参考信息 + 就医建议，关键场景强提示免责声明（详见 05 号文档合规章节）。不做在线问诊开方（如需，走与持牌机构合作）。
2. **MVP 不做社区/UGC**：内容审核与运营成本远超早期团队承载力，且与"工具"心智冲突。
3. **不做电商自营**，会员 + 内容 + 后向合作为主。
4. **不做隐私换增长的广告模式**：不做开屏第三方广告，不做数据共享变现——这是与同类产品的核心差异，也是成本。
5. **海外市场暂不考虑**：产检流程、疫苗程序表、儿保体系均为中国本土深度定制，先做深一个市场。
