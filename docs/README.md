## 快速摘要

- **定位**：从备孕到育儿、一条不断档的生命记录。以结构化记录为核心，用「阶段引擎」让产品随孕周/月龄自动演进。
- **核心洞察**：母婴工具最大的问题是"阶段毕业即流失"，全流程设计的本质是把 3-4 年生命周期沉淀为一份连续的数据资产。
- **差异化**：全流程数据连续性 + 为爸爸设计的"参与者视图" + 隐私优先 + AI 报告解读；不做诊断、不做开屏广告、记录功能永远免费。
- **MVP**：孕期核心记录闭环（产检中心/胎动/宫缩/体重血压）+ 产后基础闭环（喂养/尿布/睡眠）+ 备孕基础 + 家庭共享 + 哀伤模式。
- **北极星指标**：周记录活跃用户（WRU）。
