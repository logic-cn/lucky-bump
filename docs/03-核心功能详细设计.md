# 幸孕记（Lucky Bump）核心功能详细设计

> 文档版本：v0.1
> 文档目的：逐模块定义功能的目标、交互、核心规则与边界情况，作为设计与研发的实施依据。
> 阅读约定：每个功能按「目标 / 关键交互 / 核心规则 / 边界与异常」组织；"红线提示"指只描述现象并建议就医、不做诊断的强提醒。
> 关联文档：[02-产品定位与功能架构](./02-产品定位与功能架构.md) / [04-数据模型与页面结构](./04-数据模型与页面结构.md)

## M0 建档与阶段引擎

### 0.1 首次启动引导与建档

- **目标**：3 分钟内让用户进入"当前阶段"的正确视图。
- **关键交互**：首启问卷（单选，可跳过）：`备孕中 / 已怀孕 / 宝宝已出生 / 只是先看看`。
  - 备孕中 → 录入末次月经日期与平均周期 → 进入备孕视图；
  - 已怀孕 → 录入末次月经（或直接填已知预产期 / B 超孕周）→ 计算孕周；
  - 宝宝已出生 → 录入出生日期 → 进入育儿视图；
  - 先看看 → 以"访客模式"进入，数据本地保存，注册后继承。
- **核心规则**：所有日期输入支持"不确定"降级（选大致月份，后续在档案中修正，页面标注"估算"水印）。
- **边界与异常**：拒绝未来日期；末次月经距今 > 42 周 → 提示"宝宝可能已出生，是否登记分娩"；> 3 个月 → 提示是否在备孕模式。

### 0.2 多宝宝与多旅程

- **目标**：支持双胞胎/多胎、二胎回流。
- **核心规则**：一个妈妈账户下可有多个「旅程」（每次怀孕/育儿算一个旅程）；多胎旅程下可创建多个宝宝档案，记录支持"逐个记录"与"同步记录"（如一次喂奶应用到两个宝宝）。切换旅程在「我的-宝宝档案」完成，首页顶部显示当前旅程名。
- **边界与异常**：归档旅程只读（可查看、可导出，不可修改）；哀伤旅程见 0.4。

### 0.3 阶段时钟

- **目标**：全产品唯一时间源。
- **核心规则**：孕期展示「N 周 + d」（1-40 周）；产后展示「产后第 X 天（第 X 周）」；育儿展示「X 月 X 天」。日期计算遵循 [02-§4.3](./02-产品定位与功能架构.md) 的孕周计算规则（含 IVF、B 超校正）。
- **边界与异常**：跨零点记录归属当天；孕周修正后，所有历史数据的时间戳不变，仅参照系变化（曲线按孕周重排）。

### 0.4 哀伤模式（流产/胎停）

- **目标**：极端时刻的产品尊严。这是信任的试金石，优先级 P0。
- **关键交互**：设置页 + 分娩相关场景可进入「旅程状态变更」；选择"流产/胎停"后二次确认（说明影响范围）；进入哀伤模式。
- **核心规则**：
  - 立即隐藏所有宝宝相关内容、待办、推送（不删除任何数据）；
  - 首页替换为关怀页：复诊提醒（遵医嘱时间默认 1-2 周）、心理支持资源入口、FAQ（多久可以再备孕——仅引用指南口径并注明咨询医生）；
  - 停止一切孕育营销内容与会员促销推送（硬编码，不可配置）；
  - 再次备孕时引导新建旅程，历史旅程保留并可关联查看。
- **边界与异常**：误操作可在 30 天内撤销；此功能的使用数据永不用于运营分析。

## M1 备孕（TTC）

### 1.1 经期记录与周期预测

- **目标**：周期日历 + 排卵预测，备孕第一入口。
- **关键交互**：经期开始/结束一键记录；日历视图标注：经期、预测经期、易孕窗口、排卵日、记录项圆点。
- **核心规则**：周期长度、经期长度均取近 6 次均值 ± 波动区间；预测仅对规律周期（波动 ≤ 7 天）给出明确日期，不规律周期给出区间并提示"建议记录排卵试纸/体温提高准确度"。
- **边界与异常**：孕期/产后阶段该模块自动隐藏；经期记录在产后阶段转为"恶露"与"月经复潮"记录。

### 1.2 排卵预测与排卵试纸

- **目标**：把"猜排卵"变成"看证据"。
- **关键交互**：试纸记录：拍照 + 选择结果（弱阳/阳/强阳），支持后续在图上对照比色；记录后立即刷新易孕窗口（强阳日 ± 提示"未来 24-48 小时"）。
- **核心规则**：算法优先级：试纸强阳 > BBT 双相拐点 > 周期公式（下次月经前 14 天）；多来源冲突时以最近的生理证据为准并标注"根据 X 月 X 日试纸修正"。
- **边界与异常**：照片默认本地存储；连拍多天可生成 LH 趋势小图（v1.1，用图像算法辅助判读，标注"仅供参考"）。

### 1.3 基础体温（BBT）

- **目标**：进阶备孕用户的规律证据。
- **关键交互**：晨起一键记录（支持手环/体温计蓝牙导入，v1.2）；曲线按周期分段展示。
- **核心规则**：仅接受醒来后未活动状态下测量的体温；识别双相（排卵后上升 0.3-0.5℃ 并维持）标注疑似排卵日；单点异常值（<35℃ / >42℃）要求确认。

### 1.4 同房记录（隐私敏感）

- **关键交互**：日历上一键标记；默认归属"敏感记录组"（应用锁 + 隐藏，见 M7）。
- **核心规则**：仅在易孕窗口及前 1 天出现"今日是易孕日"的轻提示（不催促、不评判）；数据仅本人可见，家庭组任何角色不可见（含管理员）。

### 1.5 备孕健康打卡

- **内容**：叶酸（默认 0.4mg/日，支持自定义剂量）、戒烟戒酒、咖啡因控制、运动、规律作息；爸爸侧打卡项（戒烟酒）在家庭组内可见。
- **规则**：打卡连续性用"温和连续计数"（断一天不清零）；不设排行榜、不做焦虑化文案。

### 1.6 孕前检查清单

- **内容**：双方孕前检查项目模板（女方：血常规/血型/肝肾功能/空腹血糖/传染病筛查/甲状腺/TORCH/妇科超声/口腔；男方：精液常规等），支持勾选完成、附加报告、自增项目；南方省份提供地贫提示。
- **规则**：医院差异大，模板仅作清单用途，注明"以医院建议为准"。

### 1.7 验孕与好孕确认

- **目标**：接住全产品最重要的转化时刻。
- **关键交互**：验孕记录（日期 + 结果：阴性/一深一浅/阳性 + 照片）；结果为阳性或一深一浅时出现「好孕确认」引导卡。
- **核心规则**：确认后触发[02-§4.4](./02-产品定位与功能架构.md) 的好孕仪式：生成好孕报（默认不含敏感信息，用户可选关闭照片）、引导补录末次月经、邀请爸爸；备孕数据（同房/试纸/体温）转入孕期旅程归档展示。
- **边界与异常**：一深一浅默认提示"2-3 天后复测"；用户不确认则保持备孕模式并温和复访。

## M2 孕期记录

### 2.1 孕周首页

- **目标**：每天打开就回答三个问题：宝宝多大了、我今天要做什么、我状态如何。
- **关键交互**：信息层级——① 孕周大卡（N 周 + d、距预产期 X 天）；② 今日待办（来自提醒引擎）；③ 快捷记录宫格（阶段动态：体重/血压/症状/胎动/宫缩/日记…）；④ 宝宝大小可视化（每周更新，水果/蔬菜类比 + 实际厘米克重，注明为统计参考值）；⑤ 家庭动态（爸爸今日做了什么）。
- **核心规则**：孕晚期（≥ 37 周）大卡切换为"随时待命"状态，突出宫缩计时与临产指引；37 周后每日文案聚焦临产准备而非发育科普。
- **边界与异常**：过预产期后文案切换为"遵医嘱关注胎心与胎动，医生可能讨论引产计划"，不做倒计时焦虑化。

### 2.2 体重管理

- **核心规则**：建档时按孕前 BMI（WHO 中国标准：<18.5 低 / 18.5-23.9 正常 / 24-27.9 超重 / ≥28 肥胖）给出孕期总增重推荐区间（参照 IOM 口径：低 12.5-18kg / 正常 11.5-16kg / 超重 7-11.5kg / 肥胖 5-9kg）及孕中晚期周增重参考（约 0.5/0.4/0.3/0.2 kg·周）；曲线叠加推荐区间带，超区间仅提示"和医生聊聊增长计划"。
- **边界与异常**：一周内体重骤增（>1.5kg）合并血压升高 → 出现水肿/血压红线关联提示。

### 2.3 血压记录

- **核心规则**：录入收缩压/舒张压/心率；≥140/90 → 提示"建议告知产检医生，必要时复测"；≥160/110 或伴头痛视物模糊/上腹疼痛 → 立即就医红线；支持同一日多次，曲线取当日代表值（首测 + 均值双视图）。
- **边界与异常**：家庭共享下血压红线事件可同步给爸爸（用户可关）。

### 2.4 血糖与 GDM 管理

- **核心规则**：糖耐（24-28 周 OGTT）前提供检查说明（空腹 8-12h）；糖耐后自动启用"血糖日记录"模板（空腹 / 餐后 1h / 餐后 2h）；参考切点（75g OGTT：≥5.1 / ≥10.0 / ≥8.5 mmol/L）超标标注"建议与医生确认 GDM 管理方案"；确诊 GDM 后提供饮食记录 + 血糖曲线 + 控糖科普合集。
- **边界与异常**：不提供胰岛素等用药建议；用药仅在"用药记录"中登记与提醒。

### 2.5 症状与情绪打卡

- **关键交互**：症状快捷选择（孕吐/乏力/水肿/失眠/腰痛/腿抽筋/便秘/烧心/情绪低落…）+ 严重度（轻/中/重）+ 自由备注；日历热力图回看。
- **核心规则**：通用红线触发词（出血、剧烈腹痛、持续头痛、胎动明显减少、破水）→ 无论在哪记录，弹出对应临产/就医指引；孕吐严重（无法进食进水 >12h）提示妊娠剧吐就医建议。
- **边界与异常**：情绪连续 3 天"低落"出现关怀内容卡（非病理化表述）。

### 2.6 hCG / 孕酮翻倍记录（孕早期）

- **目标**：服务 6-8 周"等待 B 超"期的高频焦虑（试管与先兆流产人群尤甚）。
- **核心规则**：录入检查日期与数值，自动计算相邻两次增幅与倍增时间，画对数参考带（注明"个体差异大，参考区间仅供焦虑管理，一切以医生判断为准"）。

### 2.7 胎动计数

- **核心规则**：两种官方推荐模式——① 定时法：每日固定时段数 1 小时；② 计数法：记录"感受 N 次（默认 10 次）胎动所需时长"。生成每日趋势图；连续记录后若当日计数明显低于近期均值（如 < 50%），提示"今天胎动比平时少，建议安静侧卧观察 1 小时，仍少请联系医生或就诊"；**不做"胎动=缺氧"式恐吓文案**。
- **边界与异常**：计数中可暂停；双胞胎逐胎记录（视图左右分列）。

### 2.8 宫缩计时

- **关键交互**：大按钮开始/停止，自动计算频率与时长；历史列表显示"间隔 / 时长 / 规律性"。
- **核心规则**：出现 5-1-1 模式（间隔 ≤ 5 分钟、持续 ≥ 1 分钟、规律 ≥ 1 小时）时提示"建议准备前往医院"（初产妇口径；经产妇在设置中可切换为更早提醒口径：间隔 7-10 分钟即提示）；破水状态下宫缩记录页顶部常驻"立即平躺并前往医院"提示。

### 2.9 孕期日记与纪念

- **关键交互**：图文日记 + 语音转文字；时间线回看；一键生成阶段相册（孕早期/中期/晚期）。
- **规则**：日记默认私密，分享需二次确认并默认脱敏（隐藏健康数据）。

### 2.10 待产包与临产指引

- **待产包**：三栏模板（证件类 / 妈妈类 / 宝宝类，共约 30 项，可增删），37 周起首页出现"待产包核对"入口，完成度环形图。
- **临产指引**：见红 / 破水 / 规律宫缩三大征兆的"判断 → 应对 → 是否立即去医院"决策卡（破水：无论有无宫缩，平躺并前往医院；见红：少量血性分泌物属常见先兆，伴随规律宫缩或出血量接近月经需就诊）。

### 2.11 起名工具（P1）

- 规则：性别未知时提供中性名；支持按辈分/五行/诗词等扩展（V2 商业化评估），MVP 仅做基础候选清单 + 夫妻互评（家庭组内投票）。

## M3 产检中心（孕期最高价值模块）

### 3.1 产检日程表

- **目标**：从"记在日历里靠问人"变成"自动排程、按周推进"。
- **核心规则**：建档后按国内常规产检指南自动生成 7-11 次产检日程（默认单胎、无高危；高危妊娠提示"以医生产检单为准"并支持完全自定义）：

| 孕周 | 常规项目（摘要） | 准备提醒 |
|---|---|---|
| 6-13+6（建档） | 建档、NT 超声（11-13+6）、血/尿常规、血型、空腹血糖、肝肾功能、传染病筛查、甲状腺功能、心电图 | 空腹；带身份证/医保卡；南方地区关注地贫筛查 |
| 14-19+6 | 中期唐筛（15-20 周）或无创 DNA（12-22 周）、宫高腹围 | 唐筛需准确孕周，确认是否已 B 超校正 |
| 20-24 | 系统超声（大排畸）、血/尿常规 | 无需空腹；提前 2-4 周预约 |
| 25-28 | 75g OGTT 糖耐 | 检查前空腹 8-12h；备好水与糖水时间安排 |
| 29-32 | 超声（生长发育）、血/尿常规 | — |
| 33-36 | 胎心监护（34 周起）、GBS筛查（35-37 周）、超声 | GBS 无需准备；胎心监护前吃点东西宝宝更配合 |
| 37-40 | 每周产检：胎心监护、超声估重、宫颈评估 | 核对待产包；确认入院路线与证件 |

- 频率规则：28 周前每 4 周、28-36 周每 2 周、36 周后每周；每次产检结束录入"下次产检时间"，覆盖默认排程（医生口径优先）。
- **边界与异常**：多胎、高龄（≥35）、慢性病高危因素 → 模板切换为高危提示版（更早更频），并注明需医生确认。

### 3.2 产检记录与报告归档

- **关键交互**：一次产检一条记录：日期/医院/医生/孕周 → 勾选本次项目 → 上传报告照片 → 费用记录 → 结论备注 → 下次产检时间。
- **核心规则**：报告照片按"孕周 + 检查类型"自动归档，支持检索（按项目/医院/时间）；产检记录导出 PDF（换医院就诊时直接给医生看全史）。
- **边界与异常**：照片超大时自动压缩；报告为敏感记录组（默认仅本人与受邀记录者可见）。

### 3.3 AI 报告识别与解读（E1，V1.1 会员功能）

- **关键交互**：报告拍照 → 自动裁边 → OCR 识别项目与数值 → 结构化表格（项目/结果/参考区间/异常标记）→ 逐项点击查看科普释义。
- **核心规则**：识别置信度低的项目置灰要求人工确认；解读输出仅三类：正常 / 常见偏离（附科普）/ 建议咨询医生（附该指标的意义解释）；**绝不输出疾病结论**；页面固定免责声明组件。
- **边界与异常**：识别失败降级为"照片归档 + 手动录入关键指标"；用户可一键纠正识别结果（回流训练数据需授权）。

## M4 分娩与产褥期

### 4.1 分娩登记

- **关键交互**：出生日期时间、分娩方式（顺产/剖宫产/产钳/吸引）、会阴侧切/撕裂情况、出生体重/身长、Apgar（可选）、分娩医院、多胎逐个录入。
- **核心规则**：登记后触发：产褥期时钟启动、宝宝档案生成、生成可分享「出生卡」、产检提醒自动清空并切换为产后日程（42 天检查、EPDS 2/4/6 周随访、疫苗计划）。
- **边界与异常**：未登记分娩但系统判断已过孕 42 周 → 仅温和提醒登记，不自动切换（尊重用户的节奏，分娩登记必须是用户主动行为）。

### 4.2 恶露记录

- **核心规则**：颜色（鲜红/暗红/粉/白褐）+ 量（少/中/多，以卫生巾用量为锚）+ 异常标记（血块/异味）；参考进程说明（血性 3-4 天 → 浆液约 10 天 → 白色持续 2-3 周）；红线：突然大量出血或血块持续、鲜红恶露超过 2 周、异味伴发热 → 就医提示。
- **规则**：产后 6 周后模块弱化；月经复潮记录在此转轨（母乳妈妈可能数月不复潮，文案注明正常范围）。

### 4.3 产后情绪自评（EPDS）

- **核心规则**：标准爱丁堡产后抑郁量表 10 题，建议时点为产后 2 / 4 / 6 周（提醒可关）；总分 ≥ 13 提示"可能存在产后情绪困扰，建议与家人沟通并寻求专业帮助"（附心理援助热线等资源）；**第 10 题（自伤意念）> 0 立即呈现求助资源与热线**，语气克制。
- **边界与异常**：量表结果绝对私密（默认不属于家庭组共享内容）；不做"你可能抑郁了"的标签化表述。

### 4.4 产后恢复

- **内容**：伤口记录（剖宫产/侧切，红肿渗液提示就医）、盆底肌凯格尔打卡（每日 3 组 × 10-15 次，可配呼吸引导）、腹直肌观察记录、体重恢复曲线（与孕期体重同轴展示，画出"回到孕前"进度）。
- **规则**：42 天检查提醒 + 检查结果记录（盆底肌评分等）；月子内容只做"去伪存真"清单（可以洗头、需要通风……），不提供任何月子餐电商。

### 4.5 妈妈日常（产褥期首页双卡之一）

- 汇总：今日喂养次数/时长、睡眠时长、饮水量打卡、情绪快速标记；文案基调是"照顾好你自己也是宝宝的事"。

## M5 育儿记录（0-36 月+）

### 5.1 喂养

- **目标**：疲惫状态下 3 秒完成记录。
- **关键交互**：
  - 亲喂：一键计时（左侧/右侧），结束后自动写入时长；
  - 瓶喂/奶粉：转盘或步进器输入 ml（步长 10）；
  - 吸奶：计时 + 计量（左右分开）；
  - 亲喂中可暂停/换边；计时器支持锁屏后台运行与免打扰提醒（防睡着）。
- **核心规则**：日汇总（总奶量/亲喂总时长/次数）；连续侧别提醒（连续 3 次同一侧提示换边）；奶粉冲调只展示水温提示与"按说明书比例"文案，不推荐品牌。
- **边界与异常**：夜间模式大按钮；记录可补录（昨天忘了记）。

### 5.2 换尿布

- **关键交互**：尿/便一键；便便性状选择（Bristol 婴儿适配：糊状/成形/水样/干硬）+ 颜色（黄/绿/棕/黑/白/血丝）。
- **核心规则**：红线——血便、陶土色（白）便、持续水样便伴精神差 → 就医提示； diaper rash（红臀）打卡与护理备忘。

### 5.3 睡眠

- **关键交互**：入睡/醒来一键（支持补录）；小睡与夜间自动区分；夜醒次数一键标记。
- **核心规则**：日/周睡眠报告（总时长、小睡结构、夜醒频次）；仅展示事实与温和范围参考（0-3 月 14-17h 等，标注个体差异），**不做睡眠训练方法贩卖**（海外育儿记录产品 式 AI 建议 V2 评估）。

### 5.4 成长曲线（WHO 百分位）

- **核心规则**：身高/体重/头围录入 → 映射 WHO 0-5 岁标准曲线（男/女分表，3rd/15th/50th/85th/97th 带）；单点落在 <3rd 或 >97th、或连续两次测量跨越两个百分位带 → "建议儿保时与医生沟通生长趋势"（措辞为趋势沟通而非异常结论）；早产儿按矫正月龄展示（2 岁内）并双轴切换。
- **关键交互**：录入支持语音输入（"58.5"）；儿保单拍照识别（复用 M3 的 AI 识别能力，V1.1）。

### 5.5 疫苗接种管理

- **核心规则**：按国家免疫规划程序表（2021 版）自动生成 0-6 岁接种计划：
  - 出生：乙肝①、卡介苗；1 月：乙肝②；2 月：脊灰①；3 月：脊灰②、百白破①；4 月：脊灰③、百白破②；5 月：百白破③；6 月：乙肝③、流脑A①；8 月：麻腮风①、乙脑减毒①；9 月：流脑A②；18 月：百白破④、麻腮风②、甲肝减毒①；2 岁：乙脑减毒②；3 岁：流脑A+C①；4 岁：脊灰④；6 岁：白破、流脑A+C②。
  - 支持自费疫苗（五联/13 价肺炎/轮状/手足口/水痘/流感）以可配置清单叠加，注明"自费、自愿、咨询接种门诊"。
  - 已接种记录（日期/疫苗批号/接种单位/反应备注）；漏种提醒（过期 X 天升级提醒）。
- **边界与异常**：不同省份程序细节与替代方案（如五联替代）差异大，允许用户编辑计划并保留官方默认版；接种后发热等反应提供记录模板与就医红线（>38.5℃ 持续、精神差）。

### 5.6 儿保体检

- **核心规则**：按国家基本公共卫生服务规范生成体检日程（满月、3、6、8、12、18、24、30、36 月，之后 4-6 岁每年）；体检记录（身高体重头围自动进成长曲线、视力/听力/口腔、医生建议文本 + 报告照片）。
- **联动**：儿保数据直接驱动成长曲线与里程碑视图。

### 5.7 里程碑

- **核心规则**：四维度清单（大运动/精细运动/语言/社交认知），参考时间轴（如：2 月抬头、4 月翻身、6 月独坐、8 月腹爬、10 月扶站、12 月独走、6 月认生、12 月有意叫"爸爸妈妈"、18 月单词组合）；达标日期记录 + 照片视频；**未达标不做"落后"判定**，到参考月龄未出现时文案为"每个宝宝节奏不同，如仍无此表现，建议儿保时和医生聊聊"。
- **情感设计**：里程碑达成生成纪念卡（可分享）；时间线聚合为"成长故事"。

### 5.8 辅食记录（6 月龄+）

- **核心规则**：新食物"3 天观察法"（新增食物自动建立 3 天观察窗，标记反应：皮疹/呕吐/腹泻/无异常，异常则该食物进入"待复试"清单）；月龄内容联动（6 月强化铁米粉起步 → 7-9 月肉泥蛋黄 → 10-12 月碎块手指食物 → 1 岁+ 调味过渡）；**禁忌清单强提示**：1 岁内不加盐/糖/蜂蜜/整颗坚果/鲜牛奶，3 岁内整颗坚果与果冻。
- **关键交互**：今日吃了什么（多选 + 自增食物）；过敏原仪表盘（已确认过敏食物置顶警示，家庭组同步）。

### 5.9 用药记录

- **核心规则**：药名/剂量/时间/原因/医嘱照片；两次用药间隔过近时提示核对；**不提供剂量建议**（只提供说明书拍照归档位与复诊提醒）；疫苗接种与用药记录共用时间线。

### 5.10 成长相册与时光轴

- 按月龄自动分册；支持邀请家人共同上传（家庭组权限）；每日精选生成"时光轴"；存储策略：压缩 + 会员扩容（与商业化挂钩的合理点）。

## M6 数据中心

### 6.1 指标曲线

- **核心规则**：统一曲线组件：时间轴按阶段自适应（孕期按孕周，育儿按月龄）；支持多指标同屏（如体重+血压）；异常红线数据点可视化标注；截图自动带产品水印（脱敏开关）。

### 6.2 生命周期时间线

- 聚合所有记录类型（经期、验孕、产检、分娩、里程碑、疫苗…）为一条可滚动时间线；按"周/月"分组；支持检索与筛选；这是"数据资产"感的直接载体。

### 6.3 报告体系

| 报告 | 频率 | 内容 | 用途 |
|---|---|---|---|
| 孕周周报 | 每周 | 本周记录汇总、宝宝发育、下周待办 | 仪式感 + 留存（会员免费基础版） |
| 产检小结 | 每次产检 | 本次结果结构化 + 全孕期趋势 | 就诊沟通 |
| 阶段报告 | 阶段切换 | 备孕/孕期/产褥回顾长图 | 分享传播 |
| 成长月报 | 每月 | 喂养睡眠汇总 + 成长百分位 | 育儿期核心报告 |
| 年度孕育报告 | 每年 | 全年数据故事（类年度歌单） | 自传播增长点 |

- 所有分享图默认脱敏；会员解锁高阶图表与无水印导出。

### 6.4 数据导出与迁移

- **核心规则**：一键导出全量数据（结构化 JSON + 可读 PDF 摘要 + 原始照片打包）；换机迁移（本机加密备份文件）；删除账户 = 30 天冷静期后彻底删除（含云端）。

## M7 家庭共享与隐私

### 7.1 家庭组

- **角色**：管理员（妈妈，唯一）/ 记录者（爸爸，可记录可看，敏感组按授权）/ 围观者（长辈，只读非敏感内容）。
- **核心规则**：邀请通过口令/微信分享；每个数据组（产检/报告/情绪/同房/验孕/日记）可单独设置对"记录者"开放与否；**情绪自评（EPDS）与同房记录永远仅本人可见**（产品级不可授权，写进隐私声明，这是态度）。
- **爸爸端视图**：首页改为"今天宝宝多大 + 今天该我做什么（陪产检/带产检报告/夜里帮拍嗝打卡）+ 她最近的状态（仅展示她授权的：如'最近睡眠 5.2h，多关心她'）"；同时保留完整记录能力（喂奶/换尿布/夜奶打卡记录到同一数据流）。

### 7.2 隐私与安全

- 应用锁（FaceID/指纹/密码，默认建议开启）；敏感记录组（同房/验孕/情绪/报告）默认隐藏，需要手动查看；"隐私清单"页：谁在什么时间看了什么（重要动作留痕）；通知内容脱敏（锁屏通知只显示"你有 1 条新提醒"）。
- **核心规则**：本地优先，云备份默认关闭，开启时强提示加密与用途；接入任何第三方分析 SDK 需在隐私政策中逐项列明。

## M8 AI 助手

- **目标**：把记录变成洞察，把搜索变成对话。
- **三个场景**：
  1. **报告识别与解读**（见 3.3）；
  2. **指标洞察**：周报中生成自然语言小结（"本周血压平稳，平均 118/76"）；
  3. **问答**：基于当前孕周/月龄 + 用户数据上下文回答场景问题（"我现在 26 周，能坐飞机吗"），回答附来源性质标注与免责声明，超出知识边界的问题一律引导就医或专业渠道。
- **核心规则**：免责声明组件在所有 AI 输出固定存在；问答不输出剂量、不输出诊断、紧急关键词（出血/破水/胎动消失/高热惊厥）直接返回急救指引卡；对话记录默认不用于训练（可选授权）。

## M9 提醒引擎

- **规则类型**：① 绝对日期（下次产检）；② 相对孕周（28 周起每 2 周产检）；③ 相对月龄（6 月龄辅食、8 月龄儿保）；④ 周期打卡（叶酸每日 21:00）；⑤ 计时类（宫缩/亲喂计时结束提示）。
- **策略**：默认免打扰时段 22:00-7:00（产后 3 月内默认延长到 7:30）；紧急级（临产红线、自伤风险资源）不受免打扰限制；同一时段最多合并 3 条推送为 1 条摘要；所有提醒可逐条关闭。
- **边界与异常**：提醒未处理超过 24h 降级为首页待办，不再重复推送（对抗通知疲劳）。

## M10 会员与商业化（概要）

| 层 | 内容 |
|---|---|
| 免费版 | 全部基础记录、提醒、基础曲线、社区知识、基础周报 |
| 会员（订阅） | AI 报告解读、高阶图表与报告导出、云备份扩容、时光轴无限存储、阶段报告长图、专属客服 |
| 内容付费 | 专家课程（分娩呼吸课/辅食课等），与内容方分成 |
| 精选商城（V2） | 按阶段推荐母婴用品（记录数据驱动选品：如糖耐前推低 GI 食谱），严守"不推送广告"承诺，仅作编辑精选 |

**商业化红线**：不卖数据、不做开屏第三方广告、哀伤模式下零营销；会员不打断任何记录功能（记录永远免费，这是信任承诺）。
