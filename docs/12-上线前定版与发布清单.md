# 上线前定版与发布清单（v1.0.0）

> 2026-11-02 定版。本版之后进入**功能冻结**：不再新增功能，只做缺陷修复、体验优化与上线准备。

## 1. 定版范围（本版交付）

### 30 天清单（全部完成）

| 项 | 交付内容 | 位置 |
|---|---|---|
| 登录方式 | 手机号 + 短信验证码登录/自动注册（默认 Tab）；账号密码保留；短信未配置时自动引导到密码登录 | `pages/account/login.uvue`、`lucky-id.sendSmsCode/loginBySms` |
| 短信账号安全 | 短信用户可用「注销」二字确认注销；验证码登录自动撤回冷静期注销；密码账号仍需密码 | `lucky-id.requestDeletion`、`pages/me/privacy.uvue` |
| 旅程管理 | 「我的旅程」页：当前标记、切换、重命名、归档回退；`currentJourneyId` 服务端持久化 | `pages/me/journeys.uvue`、`lucky-journey` |
| 埋点修正 | 记录写入改为**服务端埋点**（所有记录类型），移除重复客户端事件；新增报告/提醒/家庭/旅程/反馈事件 | `common/lucky-auth-common.logEvent`、各云对象 |
| 运营看板 | 管理员只读看板：用户/旅程/宝宝数、7/30 天活跃、记录类型分布、激活漏斗、待处理反馈 | `pages/me/ops.uvue`、`lucky-analytics.opsSummary` |
| 合规 | 敏感个人信息单独同意（引导页强制 + 首页补同意门 + 隐私页可补）；协议版本/生效日期统一；注销级联清理新增表 | `utils/legal.uts`、`pages/onboarding`、`pages/index`、`lucky-maintenance` |
| 反馈入口 | 应用内意见反馈（带版本/平台/联系方式），关于页与隐私政策文案对齐 | `pages/me/feedback.uvue`、`lucky-id.submitFeedback` |
| 权限清理 | 移除未使用的 HealthKit 权限声明 | `manifest.json` |

### 本轮补齐的既有功能（定版基线）

里程碑与纪念卡、辅食 3 天观察、用药记录、饮水记录、儿保体检、周期/阶段/年度报告、发育科普卡、新旅程闭环；v5 可访问性（对比度令牌、动作色、点击区、空态）。

## 2. 上线前必须完成的外部配置

| 配置 | 目的 | 操作 |
|---|---|---|
| `uni-config-center/lucky-sms/config.json` | 手机号验证码登录 | 按 `config.example.json` 填 appId、模板 ID、短信 Key/Secret；云函数关联 `uni-cloud-sms` 扩展库；模板变量需含 `code`、`validMin` |
| `uni-config-center/lucky-ops/config.json` | 运营看板 | 填入运营管理员 uid（可在用户表按用户名查 `_id`） |
| 云端上传 | 新表/新方法生效 | 上传 `lb-child-health`、`lb-sms-codes`、`lb-feedback` schema 与全部 `.index.json`（索引）；重新上传 `lucky-id/lucky-journey/lucky-record/lucky-baby/lucky-care/lucky-data/lucky-family/lucky-analytics/lucky-maintenance`；`lucky-id` 已声明 `uni-cloud-sms` 扩展 |
| 真实联系方式 | 隐私政策与应用商店 | 当前仅提供应用内反馈；商店通常要求开发者邮箱/网址，需替换为真实联系方式 |
| 服务端推送 | 远程触达（本版未含） | uni-push 控制台开通 + 推送证书；接入计划见 docs/11 |
| 法律复核 | 用户协议/隐私政策 | 本版文案已版本化，但仍需法务确认后替换生效日期与联系方式 |
| 云打包证书 | Android/iOS 安装包 | 需 DCloud 账号、Android 签名证书、iOS 证书/描述文件；可用 CLI `pack` 或 HBuilderX 界面 |
| 云空间额度 | 上传与云打包 | 当前空间提示 `PrePayResourceExhausted`（资源额度耗尽），需在 DCloud 控制台续费/升级后重传 `lucky-maintenance` 并执行云打包 |
| 已有 schema 增量 | 用户表新字段/事件枚举 | CLI 会跳过已存在 schema，需在 HBuilderX 中右键 `uni-id-users.schema.json`、`lb-events.schema.json` → 上传 |
| 第三方登录（可选） | 微信 / Apple 一键登录 | 需开放平台 AppID、Universal Link 与 Apple Sign in 能力；本版未接，手机号为主路径 |

## 3. 本机 HBuilderX 已完成（2026-11-02）

- 项目已导入 HBuilderX（lucky-bump，云空间 `<旧阿里云空间ID>`）。
- Web 编译通过；**App（vapor 字节码）本地编译通过：54 页 + 全部组件，无警告**。
- 修复编译警告：移除 `<text :lines>` 与 `text-decoration: line-through`。
- 生成并配置安装包图标：`static/app-icons/`（Android 四密度 + iOS 1024 无 Alpha）。
- 生成并配置 Android 启动图与 Android 12 Logo：`static/splash/`。
- 新增 iOS 隐私清单：`nativeResources/ios/PrivacyInfo.xcprivacy`（`plutil` 校验通过）。
- 已通过 CLI 上传云端：11 个云对象（lucky-analytics/baby/care/data/family/id/journey/probe/record/reminder/seed）与 3 个新 schema（lb-sms-codes/lb-feedback/lb-child-health）；云端旧版本已备份到 `/tmp/lucky-bump-cloud-backup`。
- **打包预校验**：`cli pack --precheck` Android 0 error/0 warning；iOS 0 error/1 warning（仅安装包超限计费提示）；Android 包名使用 `com.luckybump.app`。
- **通知权限**：HBuilderX 5.25+ Android 不再自动申请通知权限，已在首次同步待办时主动申请 `POST_NOTIFICATIONS`。
- **Web 选择器**：HBuilderX 5.34 vapor Web 下页面栈返回会重建页面、丢失表单状态，Web 端改为**页面内 DOM 浮层**（`utils/pickDate.uts` 的 `webPick`），不再跳转页面；App 端仍使用独立 `date-picker` 页。
- **商店文案**：见 [13-商店上架文案与素材清单](13-商店上架文案与素材清单.md)。
- **阻塞**：`lucky-maintenance` 上传失败（阿里云 `PrePayResourceExhausted`，云空间资源额度耗尽）；已存在 schema 的增量（uni-id-users 新字段、lb-events 枚举）被 CLI 跳过（CLI 不支持覆盖已有 schema），需 HBuilderX 界面右键上传。
- 索引文件 `.index.json` 是否随 schema 上传生效需在 uniCloud 控制台「索引管理」确认；CLI 未提供索引上传命令。

## 5. 回滚方案

- 客户端：保留上一版安装包与云函数快照；schema 均为新增表，不做破坏性变更，回滚只需回传上一版云对象。
- 数据：新增表独立，不影响旧版本读写；如短信服务异常，客户端自动降级到账号密码登录。
- 门禁：`ui.test` 对比度/动效/尺寸断言与 `features-v15`、`account-journey-ops` 回归测试必须保持全绿。

## 6. 本版之后的节奏

- **只做**：缺陷修复、性能与稳定性、合规/商店反馈、内容运营与数据看板迭代。
- **不做**：新功能、社区/商城/广告、会员付费墙（记录永久免费红线）。
- 新一轮功能规划需先复盘本版北极星指标（WRU）与激活漏斗，再决定是否解冻。
