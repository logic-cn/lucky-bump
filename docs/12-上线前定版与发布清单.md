# 上线前定版与发布清单（v1.0.0）

> 2026-11-02 定版。本版之后进入**功能冻结**：不再新增功能，只做缺陷修复、体验优化与上线准备。

## 1. 定版范围（本版交付）

### 30 天清单（全部完成）

| 项 | 交付内容 | 位置 |
|---|---|---|
| 登录方式 | 手机号 + 短信验证码登录/自动注册（默认 Tab）；账号密码保留；短信未配置时自动引导到密码登录 | `pages/account/login.uvue`、`lucky-id.sendSmsCode/loginBySms` |
| 短信账号安全 | 短信用户可用「注销」二字确认注销；验证码登录自动撤回冷静期注销；密码账号仍需密码 | `lucky-id.requestDeletion`、`pages/me/privacy.uvue` |
| 旅程管理 | 「我的旅程」页：当前标记、切换、重命名、归档回退；`currentJourneyId` 服务端持久化 | `pages/me/journeys.uvue`、`lucky-journey` |
| 埋点修正 | 记录写入改为**服务端埋点**（所有记录类型），移除重复客户端事件；新增报告/提醒/家庭/旅程/反馈事件 | `common/lucky-auth-common.logEvent`、各云对象 |
| 运营看板 | 管理员只读看板：用户/旅程/宝宝数、7/30 天活跃、记录类型分布、激活漏斗、待处理反馈 | `pages/me/ops.uvue`、`lucky-analytics.opsSummary` |
| 合规 | 敏感个人信息单独同意（引导页强制 + 首页补同意门 + 隐私页可补）；协议版本/生效日期统一；注销级联清理新增表 | `utils/legal.uts`、`pages/onboarding`、`pages/index`、`lucky-maintenance` |
| 反馈入口 | 应用内意见反馈（带版本/平台/联系方式），关于页与隐私政策文案对齐 | `pages/me/feedback.uvue`、`lucky-id.submitFeedback` |
| 权限清理 | 移除未使用的 HealthKit 权限声明 | `manifest.json` |

### 本轮补齐的既有功能（定版基线）

里程碑与纪念卡、辅食 3 天观察、用药记录、饮水记录、儿保体检、周期/阶段/年度报告、发育科普卡、新旅程闭环；v5 可访问性（对比度令牌、动作色、点击区、空态）。

## 2. 上线前必须完成的外部配置

| 配置 | 目的 | 操作 |
|---|---|---|
| `uni-config-center/lucky-sms/config.json` | 手机号验证码登录 | 按 `config.example.json` 填 appId、模板 ID、短信 Key/Secret；云函数关联 `uni-cloud-sms` 扩展库；模板变量需含 `code`、`validMin` |
| `uni-config-center/lucky-ops/config.json` | 运营看板 | 填入运营管理员 uid（可在用户表按用户名查 `_id`） |
| 云端上传 | 新表/新方法生效 | 上传 `lb-child-health`、`lb-sms-codes`、`lb-feedback` schema；重新上传 `lucky-id/lucky-journey/lucky-record/lucky-baby/lucky-care/lucky-data/lucky-family/lucky-analytics/lucky-maintenance` |
| 服务端推送 | 远程触达（本版未含） | uni-push 控制台开通 + 推送证书；接入计划见 docs/11 |
| 法律复核 | 用户协议/隐私政策 | 本版文案已版本化，但仍需法务确认后替换生效日期与联系方式 |
| 第三方登录（可选） | 微信 / Apple 一键登录 | 需开放平台 AppID、Universal Link 与 Apple Sign in 能力；本版未接，手机号为主路径 |

## 3. 发布前检查清单

- [ ] `npm test` 全绿（当前 129/129）
- [ ] `HBuilderX` 云打包编译通过（44+ 页）
- [ ] 真机回归：注册/短信登录（配置后）/游客引导→建档→首条记录→提醒→时间线→报告→退出→复登
- [ ] 隐私链路：引导页单独同意、首页补同意门、隐私页补同意、导出、注销、撤回
- [ ] 家庭组：邀请码复制/加入/权限矩阵/留痕
- [ ] 旅程：新建/切换/重命名/归档/二胎再备孕
- [ ] 弱网：离线记录队列、同步提示、错误重试
- [ ] 商店素材：隐私政策 URL、权限说明、截图、版本说明
- [ ] 灰度方案：指定渠道/邀请码，观察崩溃率、注册转化、D1 留存 3 天

## 4. 回滚方案

- 客户端：保留上一版安装包与云函数快照；schema 均为新增表，不做破坏性变更，回滚只需回传上一版云对象。
- 数据：新增表独立，不影响旧版本读写；如短信服务异常，客户端自动降级到账号密码登录。
- 门禁：`ui.test` 对比度/动效/尺寸断言与 `features-v15`、`account-journey-ops` 回归测试必须保持全绿。

## 5. 本版之后的节奏

- **只做**：缺陷修复、性能与稳定性、合规/商店反馈、内容运营与数据看板迭代。
- **不做**：新功能、社区/商城/广告、会员付费墙（记录永久免费红线）。
- 新一轮功能规划需先复盘本版北极星指标（WRU）与激活漏斗，再决定是否解冻。
