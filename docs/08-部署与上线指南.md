## 3.1 云存储与 Web 跨域（支付宝云）

- App 端 `uniCloud.uploadFile` 不受浏览器 CORS 限制，照片上传可直接使用。
- Web/H5 端上传会请求支付宝云存储域名 `https://u.object.cloudrun.cloudbaseapp.cn`，需在支付宝云控制台 → 服务空间 → **跨域配置 / Web 安全域名** 添加前端域名（**必须带端口**，如 `localhost:5180`；上线后加正式 HTTPS 域名，不带路径）。若配置后仍被拦截，再检查「空间详情 → CDN 安全策略」的 referer 防盗链白名单。
- 未配置跨域时，Web 端相册/日记/产检照片上传会失败，数据库与云函数调用不受影响。

## 4. 生产密钥配置（上线前必须）

| 项 | 位置 | 说明 |
|---|---|---|
| tokenSecret | `cloudfunctions/common/uni-config-center/uni-id/config.json`（新建） | `{"tokenSecret": "<64 位随机串>", "tokenExpiresIn": 2592000}`。至少 32 位；未配置、过短或仍是 `config.example.json` 占位符时，生产/云端**拒绝启动（fail-closed）**；仅 `NODE_ENV=test` 的本地测试允许回落，`lucky-seed` 会告警 |
| 短信验证码 | 同上 config.json | 可选。未配置时仅开放账号密码注册（当前默认形态） |
| 支付/推送 | 后续版本 | V1 不依赖 |

生成随机密钥：`openssl rand -hex 32`。

## 5. 运行与打包

- **真机运行**：连接设备 → 运行 → 运行到 Android/iOS 基座（首次需安装 uni-app-x 自定义基座）。
- **云打包**：发行 → 原生 App 云打包（Android 签名证书在打包面板创建/使用自有证书；iOS 需证书与描述文件）。
- **Web 发布**：发行 → 网站（uniCloud 控制台开启跨域配置）。

## 8. Web 端运行时已知限制与已落地规避（2026-10-28 端到端验证沉淀）

以下均为 HBuilderX 5.33 uni-app x（蒸汽模式）Web 端实测结论；App 端不受影响或已同步修复：

1. **uni.showModal 全部回调不触发**（success/complete/fail 均不执行）：导出提示、退出登录、移除成员、接种反应提示 4 处已替换为页面内自绘弹窗。后续新增确认/提示交互请沿用自绘弹窗，勿用 showModal。
2. **`number.toInt()` 缺失**：web 端 number 原型无 UTS 扩展方法，`main.uts` 已在 WEB 条件编译内补齐（向零截断语义）。App 端为 kotlin 原生实现，不受影响。
3. **页面内"仅使用一次的 `<input>`"编译为运行时解析的 asset 组件**（`v-uni-input`），内置组件不会全局注册 → 渲染为不可输入的空元素。`main.uts` 已在 WEB 条件编译内全局注册 Input；多 input 页面由编译器内联（`__syscom`）无此问题。
4. **`type="digit"` 输入**：部分端不支持 digit 键盘，工程内统一为 `type="number"`（6 页）。
5. **reLaunch 前写全局响应式状态**（如 `applyJourney`）会触发渲染竞态（`'set' on proxy: '_ctx'`）：登录/引导已改为"先跳转、由首页 onShow 统一拉取旅程"；宝宝组页面沿用 800ms 延迟 reLaunch 的既有模式。新增"写入全局状态后立刻跳转"的代码请遵循同一模式。
6. **开发态深链（直接刷新页面 URL）不触发页面 onShow/onLoad、且 HMR 多轮热更后模块实例可能重复**——均为 dev server 特性，发行（生产构建）无此现象。验证页面时请从真实入口导航进入。
7. **CLI 上传云函数不解析 package.json 的 file: 公共模块依赖**（GUI 行为）：工程采用"公共模块 vendor 进云对象"方案（`scripts/sync_commons.sh`），上传前请先运行同步脚本；`uniCloud-*/cloudfunctions/*/common/` 为生成物（含密钥配置），不入 git。
8. **callFunction 调云对象的参数约定**：`data={method, params[]}`，params 为参数数组（平台按 `method(...params)` 展开），请求层已封装；云端 `this` 仅暴露 getUniIdToken/getClientInfo 等上下文方法，数据库一律走全局 `uniCloud.database()`。
9. **应用锁生物识别依赖平台能力**：uni-app x 对 `uni.startSoterAuthentication` 的支持需 HBuilderX 实测（UTS 静态类型下引用未确认 API 会编译失败），当前版本运行时不调用 Soter——锁为启动遮罩 + **服务端密码校验**（`lucky-id.verifyPassword`，不发新 token），不再是"点一下即进"；`utils/biometric.uts` 已留好接入点，平台确认支持后在 `isBiometricAvailable`/`authenticate` 内补真实实现即可，页面无需改动。
10. **注销账号物理删除由定时任务执行**：`requestDeletion` 落 `purge_at`（30 天后）并立即吊销全部 token、拦截登录；`lucky-maintenance` 每日 03:00 扫描 `pending_deletion` 且到期的账号，按旅程级联删除业务数据、家庭关系、token 与账号。需在 HBuilderX 上传该云函数；未部署前到期数据只会保留，不会误删。
11. **暗色模式为 class 切换而非 `@media`**：uni-app x App 端不保证支持 `prefers-color-scheme`，页面根节点绑定 `t-light`/`t-dark` class 切换 `--lb-*` 变量（theme.scss）；lbc 组件已全部令牌化。原生导航栏与 tabBar 仍保持浅色配置，动态改栏色 API 需 HBuilderX 验证后接入。
12. **系统级推送未接入**：提醒在服务端生成待办、在首页以「今日提醒」弹层呈现（免打扰时段可配置，紧急提醒可突破）；UniPush / 本地通知依赖平台配置，接入前锁屏与后台无通知（privacy 页已注明）。
13. **dev 运行下页面生命周期不触发（HBuilderX 5.34 vapor，待排查）**：2026-10-30 实测 Web dev，页面 `onLoad` / `onPageShow`（组合式，等价 `onShow`）均不执行：首页不发起 `lucky-journey`/`lucky-data` 调用、无 token 也不跳登录页；`getCurrentPages()[0].$vm.$onShow` 为空数组。页面事件处理（点击/云调用/注册/建档）正常。已按 uni-app x 文档把 7 个页面的 `onShow` 改为 `onPageShow` 并加静态断言，但问题依旧，判断为 5.34 vapor 运行时钩子注入与页面实例不一致，需回退 HBuilderX 5.33 或向 DCloud 反馈。**该问题会导致真机/发行前的数据加载链路整体失效，属于上线阻塞项。**
